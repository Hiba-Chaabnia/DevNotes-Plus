Mock scenes

Each scene is a data object in assets/mock-scenes-defs.js. They loop on their own; drag a scrubber to step through one. Nothing on this page ships — it exists to write feature copy against.

capture

Ctrl+Alt+Q → title, template, branch scope → the note exists.

anchoring

Four lines land above the anchor; the note goes with it, 5 → 9.

branch

Branch switch filters the panel, then the tag bar filters it again.

github

No keybinding exists — the card overflow menu, then a PR URL. The badge tracks the PR state.

editor

The block editor opens as its own tab; the document builds a block at a time.

sharing

Share un-ignores the note file, so Source Control shows exactly what to commit.

mcp

Claude Code in the panel, reading and writing the notes over the MCP server.
